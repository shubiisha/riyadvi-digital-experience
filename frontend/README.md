# Riyadvi Digital Experience - Frontend

Modern, high-performance React + Vite frontend for Riyadvi Software Technologies featuring hardware-accelerated Three.js 3D web environments, Framer Motion transitions, responsive Tailwind design system, and multi-page routing.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```

## Key Technologies
- **React 18** with **Vite**
- **Three.js** for real-time 3D canvas ecosystems and interactive case studies
- **Tailwind CSS** with custom Obsidian & Gold (`#D4AF37`) palette
- **Framer Motion** for micro-interactions and route transitions
- **React Router v6** for dynamic service and case-study routing
